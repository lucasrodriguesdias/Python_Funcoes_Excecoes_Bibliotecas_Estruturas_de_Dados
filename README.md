# Python – Funções, Exceções, Bibliotecas e Estruturas de Dados

Este repositório reúne **exercícios práticos e exemplos didáticos em Python**, com foco nos principais fundamentos da linguagem.  
O material foi desenvolvido com fins **educacionais**, auxiliando no aprendizado progressivo e na consolidação de conceitos essenciais para quem está iniciando ou reforçando conhecimentos em Python.

---

## 📌 Conteúdos Abordados

O repositório contempla exemplos e exercícios relacionados aos seguintes temas:

### 🔹 Funções
- Definição e chamada de funções
- Parâmetros e retorno de valores
- Funções reutilizáveis
- Boas práticas de organização de código

### 🔹 Tratamento de Exceções
- Uso de `try`, `except`, `else` e `finally`
- Diferença entre exceções comuns (`TypeError`, `ValueError`, etc.)
- Criação e uso de exceções personalizadas
- Fluxo correto de tratamento de erros

### 🔹 Bibliotecas
- Importação de bibliotecas padrão
- Uso de funções prontas da linguagem
- Organização de código com módulos

### 🔹 Estruturas de Dados
- Listas
- Tuplas
- Conjuntos (sets)
- Dicionários
- Operações comuns e aplicações práticas

---

---

## ▶️ Como Utilizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/lucasrodriguesdias/Python_Fun-es_Exce-es_Bibliotecas_Estruturas_de_Dados.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Python_Fun-es_Exce-es_Bibliotecas_Estruturas_de_Dados
   ```

3. Execute os arquivos `.py` conforme o tema desejado:
   ```bash
   python nome_do_arquivo.py
   ```
